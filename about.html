Find Your Destiny

Play the game · Source repository

What it is

Find Your Destiny is a five-question kids personality-style result game created for the UAE children’s event project.

Game rule

Each playthrough randomly selects five questions from a bank of fifteen fantasy-themed yes/no questions.

five sampled questions → YES count → themed result group → one randomly selected fantasy result

Result groups

  • 4–5 YES answers: super group
  • 2–3 YES answers: middle group
  • 0–1 YES answers: quiet group

Each group contains three possible fantasy results. The specific result shown is selected randomly from the applicable group.

Assessment-style structure

The interaction follows the structure of a short kids personality assessment/game test: answer five questions, derive a result group from the YES count, then reveal one themed result from that group.

The implemented scoring model is the explicit YES-count rule above; no additional trait model or learner score is implemented in this repository.

Event project context

This game belongs to the same UAE children’s event project as the other kids-* game repositories.
