Find Your Destiny

Play the game · Source repository

Game rule

Each run randomly selects five questions from a bank of fifteen fantasy-themed questions. The player answers each with YES or NO.

five sampled questions → YES count → result pool → random themed result

Result thresholds

  • 4–5 YES answers: super pool
  • 2–3 YES answers: middle pool
  • 0–1 YES answers: quiet pool

Each pool contains three possible fantasy results. The specific result is selected randomly from the applicable pool.

Interpretation boundary

The displayed result is a game outcome generated by the rule above. It is not a psychological assessment, personality classification, aptitude test, educational assessment, career recommendation, or prediction of future behavior.

Project context

This game belongs to the same children’s-event project family as the other kids-* games. The repository contains this single playable fantasy quiz/result mechanic; it does not contain a multi-game platform or learner assessment system.
